# تشخيص «تعذّر تحميل المظهر» في Blogger

الرفع الصحيح يكون بملف **ARABIA-PRO-X-2026.xml** نفسه. ملف ZIP للحزمة الكاملة لا يقبله مستورد المظاهر؛ فك ضغطه أولًا. ولا تحفظ صفحة GitHub بصيغة HTML ثم تغيّر امتدادها إلى XML.

## تحقق من الملف

- أول سطر يجب أن يكون `<?xml version="1.0" encoding="UTF-8" ?>`، وليس `<!DOCTYPE html>` متبوعًا بواجهة GitHub أو صفحة دخول. يلي تصريح XML تعريف HTML الخاص بالقالب نفسه.
- تأكد أن الاسم ينتهي بـ`.xml` فعلًا، لا `.xml.html` أو `.xml.txt`.
- استخدم زر تنزيل الملف الخام/الرابط المباشر من إصدار القالب. يوجد `SHA256SUMS.txt` داخل الحزمة للتحقق من النسخة إذا احتجت.

## الرفع والحصول على الخطأ المفيد

1. احتفظ بنسخة احتياطية من المظهر الحالي وإعدادات الأدوات. استخدم مدونة اختبار أولًا؛ لا تحذف أدواتك أو تستبدل قالبك بقالب فارغ للتجربة دون نسخة احتياطية.
2. Blogger ← المظهر ← استعادة/تحميل ← اختر ملف XML المستخرج مباشرة.
3. إذا ظهرت رسالة عامة فقط، افتح **تحرير HTML** في مدونة الاختبار، والصق نص XML الكامل ثم احفظ. قد يعرض محرر Blogger رسالة أدق: اسم أداة أو عنصر أو رقم سطر.
4. انسخ نص الخطأ كما يظهر مع رقم السطر واسم الملف الذي استعملته. لا يكفي تغيير CSS أو التأكد من XML محليًا لحل خطأ خاص بمحرك Blogger.
5. إن كان الملف لا يصل إلى مرحلة التحقق أصلًا، جرّب واجهة Blogger بمتصفح مدعوم وتأكد من صلاحية حسابك لتعديل المظهر. حدّد هل الفشل عند اختيار الملف أو عند حفظه؛ لكل حالة تشخيص مختلف.

## ما تم التحقق منه في هذه النسخة

صحة XML، تفرد المعرفات، عدم تداخل مناطق التخطيط داخل أدوات، وجود Blog1 واحد، ومرجعيات التضمينات المحلية. روجعت عناصر `b:attr` وحقول المقال التقليدية مقابل أمثلة Blogger مفتوحة المصدر، ولا يوجد دليل أن حقول المقال المعتادة أو خلط إصدار التخطيط بإصدار الأداة هو سبب الرفض. عُدّل وصف التذييل ليأتي من أداة رأس الصفحة الأصلية، وعُطّل CSS التلقائي لـBlogger لتقليل تعارض التنسيق؛ هذان تحسينان، وليسا إثبات إصلاح خطأ الاستيراد.

**لم تتوفر مدونة Blogger مخوّلة لتجربة قبول الرفع.** لم يُحدد سبب رسالة المستخدم العامة بعد، لأن نص الخطأ ونوع الملف المرفوع لم يصلا. لا نزعم أن الاستيراد نجح أو أن المشكلة أصلحت نهائيًا قبل التحقق داخل Blogger.

التصميم المحدّث يطابق ترتيب المرجع: شريط علوي، شعار متوسط، قائمة زرقاء، مركز مباريات اختياري، خبر بارز وثلاث بطاقات، ثم محتوى بين عمودين على الحاسوب. على الهاتف تتحول القوائم والأخبار الثانوية والمباريات إلى عرض قابل للتمرير داخل حاوياته دون تجاوز عرض الصفحة.
