# ARABIA PRO X 2026

قالب Blogger عربي مستقل.

- [تحميل الحزمة الكاملة](ARABIA-PRO-X-2026-PACKAGE.zip?raw=true)
- [تحميل ملف XML](ARABIA-PRO-X-2026.xml?raw=true)

الحزمة تتضمن أدلة التركيب والإعلانات والمباريات والتخصيص والاختبارات، ووكيل بيانات اختياريًا، وسبع مسودات صفحات قانونية.

نجح محليًا 87 تحققًا للمتصفح، و29 فحصًا للبنية والصياغة، و6 اختبارات للوكيل. قبول الاستيراد داخل Blogger لم يُختبر على مدونة فعلية. الإعلانات والمباريات معطلة حتى تهيئتها، ولا توجد مفاتيح API في الحزمة.

ابدأ بـ INSTALLATION-GUIDE.md داخل ZIP. هذه الملفات منفصلة عن تطبيق Facemook.
