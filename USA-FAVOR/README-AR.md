# USA-FAVOR — B5

مشروع Android حقيقي بوحدتين: `Admin` و`User`، ومحرك OpenVPN مضمّن. لا يحتاج إلى خادم تطبيق خارجي.

- ملفات التثبيت في `dist`: ‏`USA-Admin.apk` و`USA-Favor.apk`، بتوقيع تطوير.
- افتح مجلد المشروع الرئيسي في Android Studio، أو افتح كل مشروع منفصلًا.
- إعداد Firebase: أنشئ Realtime Database، وفعّل Anonymous وEmail/Password، وانشر `firebase/database.rules.json`، وأضف UID المسؤول تحت `/admins/UID = true` من لوحة Firebase.
- دخول المسؤول المحلي `admin / 1234`، ثم حساب Firebase المخوّل. كلمة مرور Firebase مستقلة؛ لا تُضمَّن أسرار الإدارة داخل APK.
- ملفات `google-services.json` الحالية placeholders. يمكن إدخال إعداد Firebase العام عند تشغيل APK، أو تحويل ملفات Firebase الحقيقية عبر `tools/configure-firebase.py` ثم إعادة البناء.
- الملف المرفق الأصلي مضمن دون تغيير، ويستخدم TCP 1923. يوجد خيار UDP 1195 إضافي. لا يوجد ضمان لاستمرار خادم VPN العام أو موقعه؛ يعرض التطبيق نتيجة فحص IP الفعلية.
- الموقع الوهمي الحقيقي يحتاج إذن الموقع وتحديد USA-Favor كتطبيق الموقع الوهمي في خيارات المطور. يبدأ مع اتصال VPN ويتوقف عند فصله.
- Kill Switch يحجب مرور البيانات أثناء انقطاع النفق ما دامت الخدمة حية. للحماية بعد إنهاء العملية أو إعادة التشغيل، فعّل Always-on و«حظر الاتصالات دون VPN» في إعدادات Android.
- أعداد المستخدمين النشطين تستبعد آخر ظهور أقدم من دقيقتين. يجري تحديث الحضور كل دقيقة أثناء فتح التطبيق.
- لا يمكن تأكيد الاتصال الفعلي بقاعدة Firebase أو بخادم VPN على هاتف دون إعداد Firebase وتجربة جهاز Android. راجع `dist/VALIDATION.md` لنتائج الاختبارات وحدودها.

تفاصيل الإعداد والبناء والتراخيص في `README.md`.
